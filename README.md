## About this Fork
This fork was made because I (conc1erge) wanted a good base to create a TF2 HUD on (also because I got bored from using ToonHUD) so I could curate it to my want, this is just me being curious and learning how Source VGUI and how general TF2 HUD editing/creating works.

## Contact
If you run issues into using this edit, please let me know through various means because there could've been an update with the original HUD that I have not gotten around to doing as this has just been a one-off edit I decided to make myself and isn't a priority!

Otherwise, if you think it's something with the base HUD, contact mint on Discord through **mintuk**
