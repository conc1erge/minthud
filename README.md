## About this Fork
This fork was made because I (conc1erge) wanted a good base to create a TF2 HUD on (also because I got bored from using ToonHUD) so I could curate it to my want, this is just me being curious and learning how Source VGUI and how general TF2 HUD editing/creating works.

This branch was made because I wanted to put this HUD being on GitHub be worthy to me and it being bad with no major overhauls with stuff stolen from other huds like collyhud (which are still used here anyway grr) made me feel like redoing it; this will be made as the major version as i add more on top of it and is going to be more PASS Time focused since i've been having fun with that mode tbh, other gamemodes not guaranteed so be wary
